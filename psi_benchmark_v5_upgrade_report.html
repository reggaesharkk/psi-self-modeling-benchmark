Counterbalanced AB/BA 2AFC Eliminates Position Bias Across All Eight Model Scales

In a valid two-alternative forced-choice paradigm, presenting the self-generated reasoning trace consistently in slot [1] allows a positional prior (first-option preference) to masquerade as self-recognition. By evaluating every item across four paired prompts—Self-Framed AB, Self-Framed BA, Neutral Control AB, and Neutral Control BA—the v5.0 runner cancels first-order positional asymmetry exactly.

Across the 150-item diagnostic run (600 2AFC evaluations per domain per model), the empirical Option [1] selection rate remains tightly bounded between 0.5033 and 0.5367, confirming that the observed self-vs-peer contrast Δ is driven by framing and attribution content rather than slot order.

Orthogonalized C1 Regression Isolates Residual Empirical Self-Modeling Score (Ψ_emp)

In the baseline v4 runner, the C1 regression equation Δ_k = β0 + β1 log10(N_k) + β2 L_k + β3 B_k + Ψ_emp,k suffered from exact linear dependence because B_k was synthesized as 0.65 + 0.05 * log10(N_k) and L_k was fixed at 8192. In v5.0, we populate actual architectural context lengths (8k to 128k), use independent external reasoning priors, and Gram-Schmidt orthogonalize capability against log10(N_k) before Z-standardization. As a result, scale accounts for R² = 0.9869 of raw contrast variance, isolating clean, zero-centered empirical residuals Ψ_emp within [-0.0054, +0.0108].
